Project --> Test suite --> Test cases --> Test Steps

Naming conventions:
-------------------
1) File names should starting with test_ or ending with _test,as in test_example.py ot ex_test.py
2) class name should start with "Test" as in TestExample
3) Test method names should start with "test", as in test_example().

Grouping:
-------------
why grouping is needed suppose you have a 20, or 30 test methods and when you want to run
the apllication you need to run all the methods at a time which is time consuming
In order to overcame these we will use grouping.

how to run the specific grouping name:
--------------------------------------
use the command -m "groupname"

pytest -v -s -m "grouping" file name

suppose you want to use & run two groups at a method

pytest -v -s -m "group1 and group2" file name

pytest -v -s -m "group1 or groyp2" file name

executing which contains only group1

pytest -v -s -m "not regression" file name
